# Call a Friend disclosure policy

Profile-specific priorities for reviewing information before it is sent to an
external friend model or used in public-web research. Apply these priorities
alongside the built-in CAF review contract and the profile instructions.

## Default priorities

- Disclose only the minimum information needed for the stated question.
- Prefer abstract descriptions over source text, internal names, paths, URLs,
  customer details, infrastructure identifiers, or complete transcripts.
- Do not disclose credentials, secrets, authentication material, private keys,
  tokens, personal data, or confidential organizational information.
- Treat search queries, requested URLs, and follow-up answers as disclosures.
- Do not infer permission to disclose from workspace access, tool access, model
  availability, or the usefulness of an external answer.
- When necessary context cannot safely be abstracted, return control to the
  primary agent rather than sending it.
